## Architectural Summary

1. **Centralized Manifest**: `src/lib/state-image-manifest.ts` defines the single source of truth with typed `StateId`, raw Pinterest short links, canonical pin URLs, high-resolution source assets, Cloudinary public IDs, and Cloudinary edge fetch delivery URLs.
2. **Cloudinary Dynamic Optimization Pipeline**: Every state card delivers responsive visuals using: `f_auto, q_auto, c_fill, g_auto, w_1200, h_675`.
3. **State Exhibition Integration**: `src/lib/states-data.ts` exhibition cards updated with 36 distinct cultural hero images while strictly preserving all regional culinary, textile, folk festival, and heritage gallery pillars.
4. **Monochromatic Tint Compatibility**: `src/lib/cloudinary.ts` updated to cleanly parse and unnest Cloudinary URLs, enabling live state-specific tint transformations (e.g. `e_tint:60:5B0E1B` for Rajasthan) without double-wrapping.
5. **Production Build & Verification**: Next.js production build compiled cleanly across all 17 routes with 0 errors. Authenticity test suite passed 16/16 tests.
